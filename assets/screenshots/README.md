# Screenshot animations

Replace the website placeholders with these exact files:

- `normal-play.gif` — the large hero animation
- `piano.gif` — Piano keyboard taps, a short swipe, and gentle key tints
- `ripples.gif` — a few slow expanding ripples

Keep each GIF short, silent, smoothly looping, and free of personal or device-identifying
content. Capture only the app surface. Avoid rapid cuts or flashing, and optimise the
files before committing them so the support page stays lightweight.

When an animation is ready, replace the corresponding placeholder `<div>` in
`index.html` with an `<img>` using the same descriptive caption as its alternative text.
For users who prefer reduced motion, consider adding a static first-frame image through
the HTML `<picture>` element when the final captures are prepared.
